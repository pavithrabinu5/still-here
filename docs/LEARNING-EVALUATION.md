# Learning evaluation plan — not yet run

**Status: hypothetical.** No human participants have used Still Here. No learning outcome is claimed. AI role-play is not evidence and was not used as such.

## Source-backed questions (pre/post, ~3 minutes)
Each question maps to a learning objective (LO1–LO5 from the brief).

1. (LO1) What is the Apollo 11 laser reflector, and why did astronauts set it up? *Key: a panel of 100 corner-cube mirrors (S4) placed so lasers on Earth could bounce light off it and measure distance (S1, S4).*
2. (LO2) Why does the reflector not need electricity? *Key: it only sends back light from an Earth laser; it has no battery, radio or panels (S1).*
3. (LO3) A pulse returns after 2.6 s (practice value). Write the calculation for the one-way distance, and explain the ÷2. *Key: c × 2.6 s ÷ 2; the time covers out and back.*
4. (LO4) Name one thing scientists must do after detecting returned light, before they trust a distance. *Key: any one of calibrate the instrument, quality-check or combine returns, correct for the atmosphere or motion (S3, S4).*
5. (LO4/LO5) True or false: "One returned pulse showed the Moon is moving away." *Key: false — the result comes from decades of data across several reflectors (S4).*
6. (LO5) Give one reason equipment left on the Moon can still be useful decades later. *Key: passive hardware keeps working while Earth-based teams keep measuring (S1, S3).*

Scoring: 0/1/2 rubric per item (absent / partial / complete). The rubric must be fixed before any data is collected.

## Fair comparison
- **Comparison material:** NASA's own explainer, "Laser Beams Reflected Between Earth and Moon Boost Science" (S4). It is the strongest relevant official explanation we found. Use the full article, as published, with its images.
- **Design:** randomly assign learners aged 10–14 to Still Here or the NASA article. Give each group the same time limit (about 10 min), the same pre-test and post-test (above), and a delayed retest after about 1 week if possible.
- **Controls:** same device type, same instructions, no help from facilitators. The question writers should not score answers blind to condition unless a second rater is used.
- **Outcomes:** post minus pre score per learning objective; time on task; a 3-item engagement rating; open-ended misconceptions (especially "the reflector has a battery" and "one pulse proves recession").
- **Ethics:** participants under 18 need parent or guardian consent. Following the Space Apps rules, do not record or show minors' names, faces or voices in any submission.
- **Honest reporting:** report the sample size, effect sizes with uncertainty, and null results. A tiny pilot (n under 20) can show usability problems but cannot show superiority.
